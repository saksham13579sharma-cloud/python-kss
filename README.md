# My Profile Page

Welcome to my personal profile webpage created using HTML.

## About the Project

This project is a simple personal webpage that demonstrates the basic
structure and usage of HTML.

The webpage contains information about me, my course, interests,
skills, and contact information.

## Technologies Used

- HTML5
- Git
- GitHub
- Visual Studio Code

## Features

- Personal introduction
- About Me section
- Course information
- List of interests
- List of skills
- Contact information
- Semantic HTML structure

## HTML Tags Used

Some of the HTML tags used in this project are:

| Tag | Purpose |
|---|---|
| `<!DOCTYPE html>` | Defines the document as HTML5 |
| `<html>` | Root element of the webpage |
| `<head>` | Contains webpage metadata |
| `<title>` | Defines the webpage title |
| `<body>` | Contains visible webpage content |
| `<header>` | Defines the header section |
| `<h1>` | Main heading |
| `<h2>` | Subheading |
| `<p>` | Defines a paragraph |
| `<hr>` | Creates a horizontal line |
| `<section>` | Defines a section |
